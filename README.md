# PCX 160 Service Dashboard

Buku servis pribadi Honda PCX 160 (PWA). Data tersimpan di browser perangkat, tidak dikirim ke server.

Pasang: Settings > Pages > Deploy from a branch > main > / (root).

Setelah mengubah file, naikkan nilai `V` di `sw.js` (misalnya `pcx160-v2`) agar HP mengambil versi terbaru.
